# FORGE/UI — Final Static Build

Backend-free HTML library for GitHub Pages.

- index.html — home
- buttons.html — actual button previews
- navbar.html — actual navbar previews
- forms.html — actual form previews
- cards.html — actual card previews
- ui-library.html — actual UI primitive previews
- architecture.html — website flow models
- prompts.html — engineered prompts

Core fixes:
- No text-only placeholder previews.
- CODE opens a standalone snippet with CSS included.
- Color and shape changes update the live preview and copied code.
- Shape options are component-aware.
- Shared 3-dot navigation closes on outside click/Escape and locks page scroll.
- Dark/light mode persists locally.
- Clipboard has a fallback for mobile browsers.
